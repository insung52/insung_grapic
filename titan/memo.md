# 액터

TiTan palantir 이동형 지휘소
- 실제로 이동 기능은 구현 x
- 4방향 감시 카메라 뷰 (bounding box 기능 x)
- RCWS 장착됨

UAV (드론)
- 시작 신호 수신 시 5초간 20m 상승 후 수신한 적군 위치까지 직선이동
- 수동 조종은 불가하지만, 사용자가 드론에 부착된 카메라를 자유롭게 각도를 변경하면서 확인 가능
- 카메라 뷰는 적군 또는 낙하산 잔해 발견 시 빨간색 bounding box 표시

UGV (탱크)
- 동역학 파라미터 기반 이동
- 주행 모드 : 대기/원격주행(수동)/자동주행
- 목적지 수신 시 해당 경로로 자동 주행
- 수동 조종도 가능
- 최대 속도 제한, 최대 기어 제한 등 부가적인 속도 조절 기능 존재
- 4방향 감시 카메라 뷰 (bounding box 기능 x)
- RCWS 장착됨

RCWS : 무인 공격 포탑
- 기본적으로 자동으로 적 감지하고 공격 하는 등의 기능을 수행.
- 적 또는 아군 식별 시 화면에 bounding box 시각화 하는 기능 존재. (실제 객체 탐지 방식 vs postprocessing 방식 고민중)
- IR(야간투시 모드) 전환 가능
- 장전/비장전 상태 전환 가능
- 사격 대기/사격 상태 전환 가능

- 2 종류의 RCWS 존재
  1. 이동형 지휘소 자체방호용 RCWS
  - 탄약 최대 600
  2. UGV 의 RCWS
  - 탄약 최대 1200

아군 30명
적군 15명
- 보행 ANIMATION 적용 및 피격 시 쓰러짐.
