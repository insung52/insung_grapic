UGV의 운전 모드 2개 (단축키 또는 명령어로 전환 가능하게)

1. 수동 주행

C:\working\TankSim  여기에 사용된 주행 매커니즘만 따로 분석해 사용해도 되고,
1차적으로 간단하게만 자체적으로 구현해도 됨. (wasd 로 이동 가능하게)

일정한 경로를 벗어나면 속도 저하, 나가면 안되는 곳은 나무같은 지형물로 시각적 차폐 + blocking volume 같은거로 막기

2. 목적지 입력 시 자동 주행

입력 : 목적지 좌표 수신

경로 주행
- MoveToLocation 호출 (AIController 모듈 사용)
- 목적지를 지형 3D 모델에 반영하여 위치 보정 수행 (Navmesh)
- PathFollowingComponent 가 경로 추종 수행
- OnMoveCompleted 함수로 도착 완료/실패 처리
- 추가적으로 이동 경로를 미니맵 시각화 등을 위해 경로 정보(points) 를 json 등 데이터로 추출이 가능한지 확인 (테스트로 콘솔 출력 등등) 

1차적으로 가속, 조향 같은 운전 물리는 무시하고 일정한 속도로 경로만 따라가게 구현

1차 씬 구성 : 
- 흰 평면 위에 여러 장애물 배치 및 navmesh 배치
- 시작 시 자동으로 ugv 가 특정 목적지로 경로 계산 후 경로 포인트 추출 및 이동 시작
- 사용자가 운전 모드를 변경하면 수동 주행 모드로도 주행 가능
- 일정 경로를 벗어날 수 없게 씬 외곽에 장애물 같은거 배치 (내가 직접 씬 구성할 예정)

씬 구성같은거 (차량 위치, 장애물 배치) 같은거는 내가함. UGV 액터 설계 같은거를 claude 가 담당함.

나중에 탱크 모델링 완료 후 전달받으면 그때 제대로 포탑 회전, 궤도 회전 등의 기능들을 구현 할 예정. 일단은 인터넷에서 간단한 탱크 모델링 받아서 진행할 예정.
