# 아군 병사 애니메이션 시퀀스 요청 (디자인팀 전달용)

## 배경

`Retarget_Maniquinn` 폴더의 리타겟 애님들(`RT_MF_Rifle_*`, `RT_MM_Rifle_Fire`)을 자체 리타게팅으로 붙여봤는데 두 가지 문제가 있음:
1. 좌/우/후진 등 방향이 실제 의도와 다르게 움직임
2. 저희 병사 스켈레톤은 **허리(Spine 최상위 본)가 사실상 루트 역할**이고 별도 Hip/Root 본이 없는 구조라, 이동 사이클 내내 허리가 완전히 고정된 채 하체만 움직여서 미끄러지듯 부자연스러움

자체 리타게팅으로 빠르게 해결될 문제가 아니라고 판단, 아래 목록을 디자인팀에 정식 요청하려 함. 리타게팅이 아니라 **저희 스켈레톤에 맞춰 직접 제작하거나, 리타게팅 후 저희 스켈레톤에서 직접 검증까지 마친 상태로 전달** 요청.

## 기술 요구사항 (전체 공통)

- **본 구조**: 허리(Spine 최상위 본)가 루트 역할 — **이동(로코모션) 애니메이션**은 이 본의 자연스러운 상하/좌우 무게중심 이동(보행 바운스)이 실제로 들어가 있어야 함. 완전히 고정되어 있으면 안 됨. (정지 포즈는 해당 없음 — 아래 "조합 가능 여부" 참고)
- **인플레이스(제자리, 루트모션 없음)**: 저희 시스템이 코드로 위치를 직접 이동시키고 애니메이션은 그 자리에서 걷는 사이클만 재생하는 구조. 루트모션이 포함되어 있으면 이동이 두 번 겹쳐서 밀림 — **루트모션 반드시 제외**.
- **루프 가능**: 시작 포즈 = 끝 포즈 (Walk/Jog/Idle 계열 전부)
- **8방향 세트의 "방향"은 몸통이 아니라 다리(스텝)만 바뀌는 것**: 캐릭터가 그 방향을 보고 걷는 게 아니라, **항상 정면(카메라/조준 방향)을 본 채로 다리만 해당 방향으로 스텝을 밟는 스트레이프** 구조. 아래 방향별 설명 참고.

## 방향 정의 (8방향 세트 공통)

캐릭터는 항상 정면을 보고 있다고 가정(총구 정면 고정), 아래는 오직 "다리가 어느 쪽으로 이동하는가"만 지정:

| 라벨 | 각도 | 설명 |
|---|---|---|
| Fwd | 0° | 정면 보면서 정면 전진 |
| Fwd_Right | 45° | 정면 보면서 우측 대각 전진 |
| Right | 90° | 정면 보면서 우측 사이드스텝(순수 측면 이동) |
| Bwd_Right | 135° | 정면 보면서 우측 대각 후진 |
| Bwd | 180° | 정면 보면서 후진(뒷걸음질) — 상체 안 돌아감 |
| Bwd_Left | -135° | 정면 보면서 좌측 대각 후진 |
| Left | -90° | 정면 보면서 좌측 사이드스텝 |
| Fwd_Left | -45° | 정면 보면서 좌측 대각 전진 |

## 무장상태 정의 (모든 항목에 공통 적용 — 헷갈리지 않게 명시)

이 문서의 모든 이동/정지 항목은 아래 둘 중 하나에 반드시 속함. 항목마다 어느 쪽인지 굵게 표시함:

- **[조준]** = 개머리판 어깨 견착, 총구 항상 정면(카메라 방향) 고정, 무릎 살짝 굽힌 전투 자세. 이동 방향과 무관하게 상체는 항상 정면 — 그래서 8방향 스트레이프가 필요함.
- **[총내림]** = 총구 아래로 내림(비전투 휴대), 팔은 자연스럽게 스윙. 이동 방향을 그대로 보고 이동해도 됨(정면 고정 아님) — 그래서 방향 세트가 필요 없고 정면 1개면 충분함.

## 합성(블렌드) 가능 여부 판단 기준 — 왜 어떤 건 요청하고 어떤 건 저희가 조합하는지

기존 `ally_move.md` 설계에서 이미 정한 원칙을 그대로 따름:

**안 되는 것 — 로코모션(걷기/뛰기) 중에 상반신만 다른 파지자세로 레이어/블렌드 하는 것.**
걷기/뛰기는 발맞춤에 동기화된 전신 움직임이라, 상반신(파지자세)과 하반신(보행)을 따로 블렌드하면 상체가 허공에 붕 뜬 채 고정되고 다리만 뛰는 이음새가 눈에 띔. 그래서 **"조준 상태로 이동"과 "총내림 상태로 이동"은 이동상태(정지/보행/구보) × 무장상태 조합마다 전신(풀바디) 클립을 따로 받아야 함** — 이게 아래 A 목록(필수 요청)의 근거임.

**되는 것 — ①정지(Idle) 포즈끼리 교체, ②순간적으로 얹히는 동작.**
- 정지 자세는 발맞춤 동기화가 필요 없어서, 하반신 베이스는 그대로 두고 상반신(파지자세)만 다른 정지 포즈로 크로스페이드하거나 어깨/쇄골 지점에서 레이어드 블렌드 퍼 본으로 갈아끼워도 이음새가 안 보임.
- 재장전, 무기 살펴보기, 피격 리액션, 둘러보기 고갯짓, 사격 반동 같은 "순간적으로 얹히는 동작"은 지속적 로코모션이 아니라서 애디티브 레이어로 얹어도 안전함.

이 기준으로 아래 B/C 목록은 시퀀스 요청 없이 저희가 조합함. (사격 반동을 애디티브로 얹을 때처럼, **상반신이 하반신의 실제 보행 사이클을 따라가는 게 아니라 "얹히기만" 하는 구조로만 씀** — 로코모션 자체를 레이어로 만드는 일은 안 함. 요청하신 "상반신만 고정되고 하반신만 뛰는" 현상은 바로 이 두 가지를 혼동할 때 생기는데, 아래 A/B 구분이 정확히 그걸 막기 위한 기준임.)

## A. 시퀀스로 반드시 요청 (로코모션 + 무장상태 조합 — 블렌드 불가)

### A-1. [조준] 서서 이동

- [ ] **Aim Walk × 8방향** (위 방향표 그대로, 보행 속도)
- [ ] **Aim Jog × 3방향** (Fwd, Fwd_Left, Fwd_Right만 — 후진/측면 전력질주는 실전에서 거의 안 써서 제외)

### A-2. [조준] 숙여서 이동

자세: 위와 동일한 조준 자세인데 다리를 더 깊게 굽혀 낮춤(무릎쏴 높이 정도), 상체는 거의 수직 유지(허리 숙이지 않음).

- [ ] **Crouch Aim Walk × 8방향**

> ※ 예전 `ally_move.md`에는 "Aim Walk(서서)를 숙인 이동에도 그대로 재사용 가능"이라고 적혀 있었는데, 이건 지금 깨진 걸 알게 된 구 리타겟 애셋을 보고 판단했던 내용이라 무효화함. 새로 받는 김에 서서/숙여서 둘 다 각각 받는 게 맞음.

### A-3. [총내림] 이동

- [ ] **Run Forward (총내림)** — 정면 전력질주 1개만. (Walk Forward 총내림은 기존 `AS_Walking` 정상 작동 중이라 재요청 불필요, 방향도 이동방향=몸통방향이라 1개면 충분)

### A-4. 자세/무장 동시 전환 (정지 상태지만, 실제로 몸이 움직이는 모션이라 블렌드로 못 만듦)

여기는 "정지 포즈 A" → "정지 포즈 B"처럼 단순 크로스페이드가 아니라, **일어서기/앉기라는 실제 체중 이동 동작**이 들어가야 해서 A 목록에 포함:

- [ ] **Cover Pop-up (Ducked→Exposed)** — 숙이고 총 내린 자세에서, **일어서는 동작과 무기 드는 동작이 동시에** 일어나서 조준 자세로 끝남. 벽 뒤에 숨어있다가 사격하려고 일어나는 동작.
- [ ] **Cover Pop-down (Exposed→Ducked)** — 위의 역방향, 조준 자세에서 총 내리며 숙여 앉음. (Pop-up 역재생으로 자연스러운지 디자인팀에서 먼저 확인해보고, 어색하면 별도 제작 요청 — 판단 맡김)

**A 목록 합계: Aim Walk(8) + Aim Jog(3) + Crouch Aim Walk(8) + Lowered Run(1) + Cover Pop-up(1) + Cover Pop-down(1) = 22개**

## B. 블렌드/레이어로 저희가 직접 조합 (요청 불필요 — 참고용으로만 공유)

전부 "정지 포즈 교체" 또는 "순간적으로 얹히는 동작"이라 위 기준상 안전함:

- **Weapon Raise (서서, 총내림→조준)** / **Weapon Lower (역방향)** — 둘 다 정지 상태에서만 발생(Idle↔Idle 크로스페이드), 기존 보유 자산인 `AS_RifleAim`(총내림 Idle) ↔ `AS_RifleIdle`(조준 Idle) 사이를 State Machine 크로스페이드로 전환. 새 시퀀스 불필요.
  - ⚠ Approach 진입 시(대형 이동 중 총을 들어올리는 순간)만 예외 — 이때는 "달리기(총내림)" 풀바디 클립에서 "걷기(조준)" 풀바디 클립으로 전환하는 것뿐이라, A 목록에 이미 있는 두 전신 클립 사이의 일반적인 State Machine 블렌드로 처리(레이어링 아님). 별도 자산 불필요.
- **Crouch Idle (총내림)** — 엄폐 Ducked(웅크림) 상태의 베이스 포즈. 정지 상태라 `AS_Crouching`(숙인 하반신) + `AS_RifleAim`의 팔 포즈를 어깨/쇄골 지점에서 레이어드 블렌드 퍼 본으로 조합. 새 시퀀스 불필요.
- **Fire 반동** — 상반신만, 애디티브로 얹음(로코모션 위에 "잠깐 얹히기"만 하고 보행 사이클 자체는 안 건드림). 기존 보유 `RT_MM_Rifle_Fire` 그대로 재생 가능, 이미 검증 완료.
- **재장전 / 무기 살펴보기 / 피격 리액션 / 미경계 둘러보기** — 전부 상반신 애디티브 레이어로 기존 것 재사용 (`AM_Reloading`, `AS_Enemy_Looking_Around` 등)
- **조준 상하 미세조정(Pitch) / 엄폐 좌우 기울임(Lean)** — ModifyBone으로 스파인 본 각도만 직접 조정, 시퀀스 불필요
- **사격선 회피(총구 미세조절)** — 별도 자세 대신 발사 보류 로직으로 대체, 불필요

## C. 블렌드로도 되지만, 있으면 더 자연스러움 (선택 요청 — 여유 되시면)

B 목록과 같은 방식으로 지금도 동작은 하는데, 전용 애니메이션으로 받으면 퀄리티가 더 좋아지는 것들. **필수 아님, 가능하면 부탁드리는 정도**:

- [ ] **Weapon Raise / Lower 전용 모션** — 지금은 두 정지 포즈 사이를 직선으로 크로스페이드해서 팔이 기계적으로 움직임. 자연스러운 궤적(아크)으로 든/내리는 전용 동작이 있으면 훨씬 자연스러움.
- [ ] **Crouch Idle(총내림) 전용 포즈** — 지금은 레이어드 블렌드로 조합하는데, 숙인 상태에서 총을 내렸을 때 팔꿈치/어깨 위치가 서있을 때와 미묘하게 달라야 더 자연스러움. 지금 조합으로도 큰 문제는 없어서 급하진 않음.
- [ ] **Walk/Run Start-Stop 전환** (Distance Matching 폴리싱용)
- [ ] **Turn in place** (총내림/조준 둘 다) — 지금은 회전 관성 시스템(캡슐 자체를 천천히 회전)으로 대체 중이라 없어도 됨
- [ ] **Crouch Aim Run Forward** — 숙인 채 전력질주, 실제로 잘 안 쓰이는 상황이라 우선순위 낮음
- [ ] **Prone Crawl Forward** — 지금 로직상 엎드린 채 기어서 이동하는 상황 자체가 없어서 안 씀
