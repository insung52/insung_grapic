# titan (문서 폴더) — 세션 공통 규칙

이 폴더는 `titan_example`(UE5.8, Perforce) 프로젝트의 개발 문서 저장소. 여러 Claude 세션이
독립적으로 작업하고 각자 문서를 남기는 방식이라, 문서가 뒤섞이기 쉬움 — 아래 규칙은 **여기에
새 문서를 만드는 모든 세션이 공통으로 지킬 것**(2026-08-31 도입, `titan_example/CLAUDE.md`와
동일한 규칙).

## 문서 작성 규칙 (필수)

1. **파일명에 날짜를 앞에 붙일 것**: `YYYY-MM-DD_짧은-주제.md`.
2. **문서 맨 위에 1줄 헤더**: `날짜 / 상태(완료·진행중·보류·설계단계) / 한줄요약`.
3. 주제별 폴더(`newlevel/`, `path/`, `soldiers/`, `structure/`, `hit_effects/`, `drone/` 등,
   없으면 신설)에 그대로 두면 됨 — 스테이징 폴더 없음. 주기적 "문서 정리" 세션이 전체를
   재스캔해서 `DOCS_INDEX.md`/`CURRENT_STATE.md`에 반영.

## 이 폴더의 최상위 문서

- `README.md` — 프로젝트 개요/시작점.
- `DOCS_INDEX.md` — 전체 문서 목록(날짜순/주제별), 정리 세션이 관리.
- `CURRENT_STATE.md` — 현재 프로젝트 상태 스냅샷, 정리 세션이 관리.
- `structure/README.md` — LIG 프로토콜/RTSP/리플리케이션/인게임 설정 등 인프라 트랙 전용
  인덱스(위 두 문서보다 그 영역에 한해 더 상세).
